# Emoji Guess Game

A browser game where you guess a movie, TV series, book, video game, anime, song, League of Legends champion, city, cartoon, food or brand from a row of emojis. Each category has its own page, answers are typed letter by letter, and already solved items are remembered in `localStorage` so they don't repeat.

## Stack

- Next.js 15 (App Router), React 19, TypeScript
- Tailwind CSS 3, Headless UI, Heroicons
- Framer Motion, react-hook-form, react-hot-toast
- Static game data in `data/categories.ts` and `data/gameItems.ts`, no backend

## Running it

```bash
npm install
npm run dev
```

Other scripts: `npm run build`, `npm run start`, `npm run lint`. No environment variables are needed.
